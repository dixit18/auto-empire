# PRODUCT DOCTRINE v2 — the pivot (grounded in YC: PG "How to Get Startup Ideas", YC Startup School, Segment PMF talk)
Read these first: paulgraham.com/startupideas.html · YC "How to Pick a Startup Idea" (Jon Xu, Jun 2026) · Segment PMF talk.

## 1. The sitcom test (we failed it in places — admitted)
PG: most made-up ideas sound plausible ("social network for pet owners") but sum to zero users. Audit of OUR 11: 04 signal bots, 07 staging, 10 generic courses, 06-broad — plausible, no one urgently needs v1 from an unknown team. Verdict: demoted to monitoring/archive. No more builds there until a user drags it out of us.

## 2. Wells, not craters (where we double down)
Good ideas start narrow + deep with a fast path out. Our three wells:
- **05 Etsy publishing** — ADHD moms + poetcore: specific shelves, real search demand, path out bundles→master→TikTok Shop.
- **11 Dental ritual** — senior small-breed owners: guilt + $600 anchor = depth; path out to pet line. Deepest pain per dollar in the portfolio.
- **12 Memory layer** — indie agent builders: WE are the user (organic idea — PG's best kind), path out sync→team→enterprise.
Everything else is search, not focus.

## 3. Tar pits we will not touch
Generic "AI wrapper for X", broad courses, generic chatbots, anything competing on "best AI" instead of a vertical outcome. 06 survives ONLY as "Etsy-seller tools" — one inch wide.

## 4. PMF test (Segment: haywire or it didn't happen)
Idle interest (polite replies, free users) ≠ PMF. Our gates, no exceptions: 10 pre-sales before filming/building (rule extends to ALL teams, not just 10); paid pilots before paid spend; kill rules in every ORG-PLAN are load-bearing, not decoration.

## 5. Founder-market fit (honest version)
We are agent-trench builders: memory, agent tooling, content pipelines = organic, full speed. Dog dental = non-organic: survives ONLY if the owner talks to 10 real dog owners this month (TASKS.md) — otherwise kill, per PG's rule.

## 6. Portfolio = search phase, then burn boats (Jon Xu)
Running 11 contradicts "burn the boats" — deliberately, TEMPORARILY. This portfolio is a search function with kill rules as the selection pressure. At first $1k real revenue in any well: boats burn, 80% of crew concentrates. Stated now so nobody confuses motion with strategy.
