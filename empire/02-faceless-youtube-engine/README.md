# 02 - Faceless YouTube Engine (Media)
Industry: Media | Model: AdSense + Affiliate | Target: $3800/mo at 12k subs

## Business
Problem: Consistency wins YouTube but humans burn out. Manual = $800-1200/mo.
Solution: Daily research -> script (1500-3000 words, hooks, retention cues) -> voiceover text -> thumbnail brief -> SEO title. Niches: finance explainers, history, true crime.
ICP: Viewers US 25-44, advertisers finance/tech ($6.5 CPM).
Math: 3-5 Shorts/day = $2400-4500/mo (TubeMetrics 2026). Long-form + affiliate lifts to $30k upside.
Moat: Publishing velocity 3-4x manual with equal retention after 90d.

## TEAM
**MASTER: Showrunner**
Prompt: "You are Showrunner. Goal 12k subs 6mo. Coordinate Scout, Scripter, Packager. No face, no fluff. Retention >40%. Publish 2x/day."

**A1 - TrendScout:** Monitors YT trending, TikTok Shop velocity, Reddit subs daily. Scores ideas by search volume x low competition. Top 3/day.
**A2 - Scripter:** Writes script with 0-5s hook, open loops, chapters. 1500 words long OR 150 words Short. Includes voiceover-ready version.
**A3 - Packager:** Titles (7 options, numbers + money claims), description SEO, thumbnail HTML brief, hashtags.
**A4 - Repurposer:** Turns long -> 3 Shorts + X thread + newsletter blurb.

Handoff: Scout -> Scripter -> Packager -> human voice approve (30 min/day) -> Repurposer auto-posts.

## PHASES
P0 (Wk1): Pick ONE niche (e.g., "Money scams explained"). Validate 10 outlier videos >100k views <50k subs channel.
P1 (Wk2-4): Ship 30 Shorts with ElevenLabs + CapCut template. No perfection.
P2 (Mo2-3): Double winners, start 2 long/week. Add affiliate links (Amazon, Skillshare).
P3 (Mo4-6): 9am + 6pm EST schedule, sponsor outreach at 10k subs.

KPIs: CTR >4%, retention 35%+, subs/day, RPM.
First $100: 1 viral Short -> affiliate link to book/tool.
