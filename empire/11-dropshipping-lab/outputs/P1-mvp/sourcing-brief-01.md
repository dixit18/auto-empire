# COLLECTION FILE 01 — Sourcing route decision (Sourcer, collected 2026-09-08)
Status: research collected, samples NOT yet ordered (needs owner: pick agent + sample budget).

## Decision: hybrid route, staged by volume
- **Test (0–20 orders): AliExpress retail, 1 supplier.** Accept 12–20 day delivery + thin margin. Purpose is ONLY creative validation (does the demo sell?), not profit. Kill fast if CTR <1.5%.
- **Scale (20–50/day): 1688 + private agent.** 1688 prices run 20–60% below AliExpress; agent adds QC, custom box, 7–12 day lines (YunExpress/SF). This is where our $6.80 landed cost comes from. Candidates: CJDropshipping (TikTok Shop integration, low friction) or BuckyDrop (1688/Taobao import + auto-fulfill) — pick ONE after sample test.
- **Brand (50+/day): 3PL / buffer stock.** 50-unit buffer drops per-unit below AliExpress; no tracking-number horror stories.

## Why not pure AliExpress (the traditional trap)
Plastic-bag unboxing kills the brand, zero QC (we never see the product before the customer), 15–30 day shipping = disputes. Fine for a $20 test, suicide at scale.

## Why not pure 1688 DIY
Mandarin-only, no international shipping, local payment only. Without an agent you ARE the warehouse. Agent fee ($0.50–2/order + 2–8% markup) is cheaper than one refund wave.

## TikTok Shop constraint (our main channel)
Shop demands 3–7 day shipping + low disputes, or the algorithm buries you. So: list on TikTok Shop ONLY once agent fulfillment is live with tracking. DTC site can start earlier with honest "ships in 3–5, arrives in 10–18" copy.
