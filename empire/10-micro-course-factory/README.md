# 10 - Micro-Course Factory (EdTech)
Industry: EdTech | Model: $19-49 course + $19/mo community | Target: $3k launch

## Business
Problem: Broad courses die. Buyers pay for ONE problem solved <2h with templates.
Solution: Factory: micro-course (90 mins) + Notion dashboard + prompt pack. Examples: "Pinterest SEO for Etsy in 90 mins", "Reddit leads in 7 days", "Polymarket starter". Teachers/homeschool bundles year-round stable.
Proof: Micro-courses + niche Notion + teacher resources = 70-95% margin, build-once sell-many.
ICP: Beginners who want clear deliverable, teachers saving time.
Math: 100 x $29 = $2900 launch + 50 x $19 community = $950 MRR. Upsell templates $35.

## TEAM
**MASTER: Dean**
Prompt: "You ship tiny, useful schools. Coordinate Researcher, Teacher, TA. One problem, 90 mins, templates included. No fluff."

**A1 - Researcher:** Finds urgent specific pain via Reddit/Amazon reviews/Ahrefs (e.g., "sight word flashcards"). Defines outcome + transformation.
**A2 - Teacher (Course Builder):** Outline -> 6 x 15-min scripts -> slides -> Loom + AI edit. Includes checklist, Notion template.
**A3 - TA (Community + Support):** Runs Discord/Skool, weekly office hour, FAQ bot trained on course (paywalled agent $39/mo upsell - links to #06 coach model).
**A4 - Marketer:** Free sample pack (10 prompts/pages) -> email -> $197 master upsell. SEO blog "AI tools for accountants/teachers".

## PHASES
P0: Pick ONE (your own pain). Pre-sell 10 @ $19 before filming.
P1: Film in 10 days (constraint = creativity). Gumroad/LemonSqueezy auto-delivery + tax.
P2: Launch to list + X build-in-public. Goal $0-300 first, $300-1200 mo3-4.
P3: Stack: course -> templates -> $19/mo group -> $149 B2B workshop for schools/agencies.

KPIs: Pre-sales (>10), completion (>40%), NPS, upsell %.
First $100: 5 pre-sales x $20 to Twitter followers.
Rule: Narrow scope, not expand. One audience, one problem, one solution.
