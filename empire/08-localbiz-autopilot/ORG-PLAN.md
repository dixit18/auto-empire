# ORG PLAN — 08 LocalBiz Autopilot (org: services retainer studio)
Mission: no missed call, no unanswered review, no empty slot — for shops that live on reputation.

## Placement
Shelf: local marketing, between DIY tools (owner has no time) and $2k/mo agencies (owner has no budget). One offer, one price band: missed-call textback + review voice + booking. Sold per vertical (salons → dentists → contractors), never generic — each vertical gets its own scripts and proof sheet.

## Pricing architecture
- Starter $199: textback + review responder, 1 location.
- Pro $399 (hero): + booking + reminders + weekly ROI sheet.
- Setup $750–1,500 once (pays CAC, filters tire-kickers).

Math: 10×$399 = $4k MRR. Retention law: the daily proof sheet (jobs rescued $) IS the product — canceling feels like firing a good employee.

## Packaging
