# 07 - Staging Interior AI (PropTech)
Industry: PropTech / Real Estate | Model: $29/mo + $99 packs | Target: $40k MRR archetype, start $2k

## Business
Problem: Agents/Hosts need staged photos that sell. Generic restyle saturated, but persona-specific wins.
Solution: Ruthlessly narrow: "Stage my Airbnb listing in 30s" + "Virtual staging for realtors". Before/after visual = free distribution every share.
Proof: Interior AI ~$40-45k MRR solo, >99% margin after GPU. Boring = durable.
ICP: Realtors staging, Airbnb hosts, remodel contractors.
Math: $29/mo x 70 = $2030 + photo packs $99. One narrow winner > suite.
Moat: Speed + cheap (Replicate GPU pennies), feature discipline (don't become suite).

## TEAM
**MASTER: Property Visual Lead**
Prompt: "You own before/after wow. Coordinate Stager, Lister, Distributor. Keep narrow. Every output shareable."

**A1 - Stager (AI):** Restyle room (Scandi, Neo Deco brass/chrome, Afrohemian mudcloth). Keeps geometry, changes decor. 3 variants/listing.
**A2 - Lister:** Writes Zillow/Airbnb description + SEO + price uplift estimate.
**A3 - Distributor:** Auto-posts before/after to X/Pinterest, tags agent. Tracks shares.
**A4 - Ops:** GPU cost guard, quality filter (hands, windows), support (founder replies in minutes = trust).

## PHASES
P0: Pick 1 persona (Airbnb hosts in 1 city). 10 free stages for testimonials.
P1: Ship boring stack (Next.js + Replicate + Stripe $19-49/mo). No suite.
P2: Launch via agent Facebook groups, $0 X marketing. Let plateau in peace - don't force doubling.
P3: Add realtor tier $49 + contractor white-label.

KPIs: Share rate (>15%), GPU cost/order (<$0.30), retention, $/listing uplift.
First $100: 5 stages x $20 to 1 realtor.
